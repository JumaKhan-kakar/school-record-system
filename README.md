# School Record System — GBMHS Ziarat

Offline-first student records app for a government school running on paper registers.
One self-contained HTML file — no server, no database, no internet needed.

## What it does

- **Admissions register** — auto admission numbers, duplicate prevention (name + father's name + DOB)
- **DOB records** — age as-of any date, board-eligibility flags (Today / 31 March presets)
- **Exams & marks** — mid-term / final-term; 8th–10th are board classes (mid-term only in school)
- **Result register** — broadsheet, grades, divisions, positions, printable A4 report cards, pass % summary
- **Science lab log** — inventory, low-stock alerts, maintenance reminders
- **Certificates** — School Leaving / Provisional, never-repeating serials, frozen snapshots, reprint / void
- **Multi-phone merge** — teachers on different phones combine data without overwriting
- **Automatic safety copies** — daily snapshots + one before every restore / merge / erase
- **Bulk entry** — CSV import, register-photo helper, voice entry, paste-from-register scan

## Use

Open the page. Everything saves permanently on that phone (offline storage).
To move data between phones: Settings → Backup → send the file → other phone Settings → Receive from another phone.
